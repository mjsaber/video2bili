# 近 7 天新选题筛选设计

## 目标

从白名单主播近 7 天的英雄战场实战视频中，选出一个尚未制作、适合双视频成片的新题材。

## 方法

1. 使用 `video2yt-topic` 的默认近 7 天窗口抓取候选。
2. 按同流派、同英雄、同饰品三个维度寻找可配对视频。
3. 用 `assets/topic/done_topics.txt` 和既有项目脚本排除已做题材。
4. 人工复核候选的时效性、两局打法互补性、机制清晰度与标题吸引力。
5. 所有候选在回复中保留两条 Bilibili 源链接，并明确一个主推选题及推荐理由。

## 成功标准

- 主推题材未出现在已完成选题中。
- 至少有两条可用实战源；优先不同主播，若同主播双局明显互补也可采用。
- 能用一句话讲清核心机制，并具备适合开场和缩略图的视觉亮点。
- 输出完整候选报告，而非省略链接的摘要。

## 异常处理

- 若近 7 天没有合格新题材，先报告结果，再建议扩大到 14 天。
- 若自动摘要中的英雄、卡牌或机制可疑，只把它列为待核实候选，不直接定题。
