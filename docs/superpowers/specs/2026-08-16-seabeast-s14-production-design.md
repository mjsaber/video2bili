# S14 新賽季海獸流單素材影片製作設計

## 目標

製作一期以「新賽季海獸流」為主題的繁體中文《爐石戰記：英雄戰場》嘗鮮影片。這是一次單素材「新發明」型內容實驗：只保留郭楓荷的完整實戰，不再為滿足雙素材結構拼接機制不同的龍蝦野獸對局。

本期不宣稱海獸流是穩定上分或可每局複製的標準陣容。內容應先用兩萬血海盜與發現後全場暴漲的可見結果吸引觀眾，再說清它由海盜經濟、金色隨從累積、發現成長與野獸戰鬥組件共同形成。

## 已確認素材

唯一來源為爐石郭楓荷：<https://www.bilibili.com/video/BV1jnuZ67Epi>

- 原標題：`新发明：思路已成，海兽流！`
- 時長：約 24:12。
- 預期用途：完整展示寶箱產生金色隨從、金色隨從提高掠奪大師鉤牙的成長幅度、反覆發現強化其他海盜，以及後期加入野獸戰鬥組件的過程。

瓦莉拉的龍蝦素材 <https://www.bilibili.com/video/BV1sYgA6CEms> 明確排除。該局以多龍蝦、達卡萊附魔師與回合結束成長為主，並非同一套海盜加野獸機制，不得下載、剪入正片或出現在 metadata 中。

## 包裝設計

### 標題

暫定主標題：

`新賽季海獸流！兩萬血海盜站場，野獸亡語瘋狂觸發`

「新賽季海獸流」必須保留在標題前半段，負責新鮮感；「兩萬血海盜站場」與「野獸亡語瘋狂觸發」分別交代兩個種族的結果與分工，讓觀眾立即理解它為什麼叫海獸流。正式發布前可依逐幀證據微調數值措辭，但不可移除「新賽季海獸流」或其中一個種族。

### 封面

- 上層小標：`新賽季`
- 中央主標：`海獸流！`
- 左側海盜標籤：`兩萬血海盜`
- 右側野獸標籤：`亡語野獸`
- 主視覺採左右對峙或匯流構圖：左側使用原片最大可靠身材的金色海盜，右側使用實際參戰的核心野獸；中間以能量、乘號或匯流軌跡建立兩個種族共同成型的關係。
- 掠奪大師鉤牙與亡語增幅組件可作第二層機制提示，但不能遮蓋海盜、野獸與主標。
- 最終縮圖沿用 `scripts/thumbnail_polish.py` 的頻道固定結構，並檢查 640×360 尺寸下「新賽季」「海獸流」和數值仍清楚可讀。

## 內容設計

### 核心主線

1. 金色上進的逃兵持續產生或加速上鎖寶箱，寶箱提供金色隨從與資源。
2. 本局使用的金色隨從越多，金色掠奪大師鉤牙在發現後給其他海盜的永久加成越高。
3. 腐鰓學徒等發現來源反覆觸發鉤牙，把資源循環直接轉成海盜身材。
4. 後期加入巨狼戈德林、透亡陸行鳥與瑞文戴爾男爵類亡語增幅組件，補充野獸戰鬥層。
5. 影片須明確指出：海盜負責主要永久身材，野獸負責後期戰鬥收益；「海獸流」是這局的創意混合終局，不是開局就能照表抓牌的固定陣容。

以上卡名均為工作名稱。正式旁白與字幕只能使用最新官方 zhTW 卡面核實後的名稱與規則。

### 影片結構

1. 45–50 秒動態 Intro，以 `你敢相信？` 開頭，先展示約兩萬血終局，再倒回寶箱與發現的成長鏈。
2. 郭楓荷完整單局實戰，保留啟動、轉型、成型與決賽脈絡；不為模仿雙素材影片而人為切成兩局。
3. 約 5 秒訂閱 CTA 附加在正片合適的自然停頓處，不獨立成章。
4. YouTube 章節至少包含 Intro 與海獸流實戰，所有章節不少於 10 秒。

### Intro 文風

- 結果先行：先說兩萬血與每次發現的巨大加成，再解釋流派名稱。
- 必須說出「新賽季海獸流」或同義完整表述，強化嘗鮮定位。
- 客觀、直接、強烈，減少擬人與鬆散比喻。
- 可以稱「新發明」「花活」或「胡牌上限」，不能稱穩定 T0、版本答案或百分百吃雞。
- 「每次發現 +78/+78」只能在逐幀確認該時點的實際卡文後使用；若加成隨金色隨從數變化，旁白要表達為成長中的當局數值，而非固定規則。

## 證據與術語

- 下載唯一來源的 1080p 原片、XML 與 ASS 彈幕，並做完整音影片解碼。
- 只執行一次 `video2yt-subtitle --skip-cleanup` 原始 ASR；已有與當前 MP4 匹配的 canonical cache 時直接復用。
- 完整讀取 raw ASR、彈幕與關鍵幀，建立帶 BVID 和時間戳的機制證據表。
- 使用最新 HearthstoneJSON zhTW 資料及官方 512 px BGS 卡面核實英雄、飾品、海盜、野獸與所有口播卡名。
- 分開記錄靜態卡文、寶箱的隨機產出、每次發現時鉤牙的當前加成、海盜最終身材與野獸戰鬥觸發；不能把單局隨機結果描述為固定效果。
- 自動選題報告中「龍蝦亡語藏入魚人」的舊摘要已判定錯誤，不得用作旁白或剪輯依據。

## 單素材規則

- 本期採用推薦方案：在製作規範中記錄「經人工確認的新發明型內容可使用單素材」，不修改 `video2yt-topic` 的自動配對算法。
- 是否屬於新發明型內容由人工檢查實際機制、獨特性、結果張力和單局完整度後決定；不能只因原作者標題含「新發明」就自動入選。
- 單素材仍須完成下載、ASR、彈幕、逐幀證據和官方繁中術語核驗，不能降低內容理解標準。
- 後續若來源機制不成立或終局證據不足，停止製作並重新選題，不添加不匹配的第二素材補位。

## 執行與審核邊界

1. 建立獨立專案 `output/seabeast_s14/`，在 `WORKFLOW_NOTES.md` 中記錄唯一來源、排除來源與單素材規則。
2. 下載並驗證唯一素材，完成 stems、一次 raw ASR、彈幕與關鍵幀分析。
3. 寫入 `content_understanding.md`、`terms_zhTW.md`、`subtitle_context.txt` 和 `intro_script.txt`。
4. 第一次審核向使用者同時展示機制理解、可靠數值、完整 Intro 以及標題／封面文案。
5. Intro 與包裝獲批後才進入 TTS、背景、正片燒錄、CTA、合併、封面、metadata 和上傳。
6. 本期尚未取得公開上傳授權；不得因選題確認而推定可以上傳。

## 驗收標準

- 唯一來源可完整解碼，解析度為 1920×1080，原始 ASR 與彈幕覆蓋完整對局。
- 正片與 metadata 中不存在第二條龍蝦素材或其作者資訊。
- 每個 Intro 機制和數值斷言都能指向原片時間點與官方繁中卡面。
- 清楚區分寶箱經濟、金色隨從累積、發現觸發、海盜永久身材和野獸戰鬥增幅。
- 標題前半段含「新賽季海獸流」，並同時說明海盜與野獸的分工；封面同時可讀「新賽季」「海獸流」「兩萬血海盜」與「亡語野獸」。
- Intro 為 45–50 秒預估口播量，保持嘗鮮感但不誇大成穩定攻略。
- 第一次審核前不生成 TTS、不燒錄正片、不上傳。

## 失敗處理

- 下載流損壞時切換可靠格式並重新完整解碼，不在損壞素材上繼續。
- 官方繁中名稱與來源簡中名稱不同時，以官方 zhTW 卡面為準，並在術語表記錄對照。
- 若兩萬血或 +78/+78 屬於短暫畫面、對手數值或無法可靠確認，收窄標題和 Intro，不保留錯誤數字。
- 若野獸只占極小的終局插件比例，Intro 直接說明「海盜成長、野獸補戰鬥」，不把它包裝成對半混合的固定陣容。
