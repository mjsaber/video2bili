# S14 下一期选题筛选设计

**日期：** 2026-08-07
**状态：** 对话方案已批准，等待书面规格确认

## 目标

从近期《炉石战记：英雄战场》第 14 赛季视频中筛出下一期最适合频道制作的双主播题材。候选必须突出 S14 新卡、新机制、黑暗贈禮或由新随从池形成的新体系，并与已经完成的「抉擇野豬」和「魚餌野獸」保持题材差异。

## 扫描范围

- 使用现有 `video2yt-topic` 管线扫描白名单主播最近 7 天的视频。
- 使用浏览器登录 Cookie 获取 Bilibili 视频信息、弹幕和可用实战来源。
- 先执行完整 7 天扫描；合格候选少于 3 个时，再用实际出现的 S14 卡名、流派名和社区别称定向补搜。
- 不用 S13 旧对局、构筑模式视频或其他游戏的视频补足数量。

## 去重与准入规则

候选必须同时满足：

1. 至少有两位不同白名单主播的完整实战来源。
2. 内容能由视频、弹幕或画面确认属于 S14，而不是只在标题中写“新版本”。
3. 有明确的机制链、运营节点或成型路径，适合做完整教学。
4. 有可用于 Intro 和缩略图的强战力兑现、极限数据或连锁效果。
5. 未出现在 `assets/topic/done_topics.txt`，且不是既有项目的同义改名。

本轮明确排除：

- S14 抉擇野豬及其同义题材。
- S14 魚餌野獸及其同义题材。
- 已发布的老虎、跳蛙、甲蟲、死海、後撤步龍、娜迦倒轉、背靠背等历史题材复刻，除非 S14 新卡形成了可独立命名、机制明显不同的新体系。

## 排序标准

候选按以下优先级排序：

1. S14 新鲜度与版本关联强度。
2. 两位主播素材的互补性，而不是同一套流程的重复展示。
3. 机制解释价值和观众可复现性。
4. 冷开场、标题和缩略图的冲击力。
5. 素材时长、画质、弹幕和语音完整度。

## 输出格式

- 保存标准报告至 `output/topics/2026-08-07.md`。
- 聊天中每个候选都显示对应的完整 Bilibili 来源链接，不能只给标题或 BV 号。
- 给出 3 个优先候选；若真实合格候选不足 3 个，按实际数量输出，不用旧题凑数。
- 对每个候选说明：S14 依据、两段素材差异、核心机制、成片卖点和潜在风险。
- 给出唯一首选，并说明它相对其他候选的优势。

## 失败处理

- Bilibili Cookie 或风控失败时，报告真实错误并按 CLI 支持的浏览器 Cookie 路径重试，不伪造候选。
- 汇总超时时保留已抓取数据并重跑汇总，不根据标题直接猜机制。
- 标题、弹幕和画面发生冲突时，以下载后的实际内容为准。
- 同一流派只有一位主播素材时，降级为储备候选，不进入前三推荐。

## 完成标准

- 当日报告存在且包含可点击的 Bilibili 链接。
- 每个正式候选至少对应两位主播。
- 所有候选都经过 S14 归属与已做题材去重检查。
- 首选具有清晰的新版本机制、双素材互补性和强视觉兑现。
