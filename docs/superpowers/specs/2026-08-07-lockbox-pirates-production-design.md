# S14 帶鎖箱海盜双视角视频制作设计

**日期：** 2026-08-07
**状态：** 用户已批准书面规格，可以进入制作
**项目目录：** `output/lockbox_pirates_s14/`

## 1. 目标

制作一期突出《炉石战记：英雄战场》第 14 赛季海盗新经济循环的完整教学视频。正片采用郭枫荷与瓦莉拉两条完整实战，核心卖点不是泛化的“海盗电表”或旧罗杰斯体系，而是 S14 新增的「積極的逃脫者／帶鎖箱」资源链如何把持续花费金币转化为金色随从计数，再放大后期海盗属性增益。

封面必须把“新经济循环”作为第一卖点，固定使用：

- 上层：`鎖箱海盜`
- 下层：`新經濟循環`

## 2. 源视频

1. 郭枫荷：[极致手速！场均6千海盗倒转——酒馆战棋新版本](https://www.bilibili.com/video/BV1Lw3U6xEJp)，约 23:31。
2. 瓦莉拉：[【炉石瓦莉拉】酒馆战棋新版本 海盗又进入到了他的舒适区](https://www.bilibili.com/video/BV1uSMU6kEzB)，约 17:52。

两条素材先串行下载并验证 1920×1080、音轨、时长和弹幕。随后分别执行 stems 与一次 `--skip-cleanup` raw ASR，Intro 只使用 speech、弹幕和画面能够共同支持的实际机制与战果，不根据扫描摘要直接写最终旁白。

## 3. 叙事与机制说明

Intro 机制说明比上一期更完整，目标时长约 45–50 秒。封面虽然突出“新经济循环”，旁白必须同时说明经济卡、成长卡和终局卡各自的独立机制，不能把所有新卡笼统概括成“刷钱”。必须按真实触发顺序讲清楚以下闭环：

1. 「積極的逃脫者」每花费 5 枚金币就提供一张「帶鎖箱」；如果已经持有锁箱，则让它提前一回合开启。
2. 「帶鎖箱」经过倒计时后提供一张拥有类型的随机金卡手下，把持续买卖转化为稳定金卡来源；获得后仍须实际打出，才会计入成长卡的本局计数。
3. 「『大師掠奪者』鉤牙」不是经济卡：它在每次发现卡牌后强化其他海盗，基础增幅还会随本局已经打出的金卡手下数量提高，把金卡计数转化为其余海盗成长；它不强化自身，静态卡文也没有公开逐张金卡的具体提升公式。
4. 「被關押的叛亂者」以死亡之声再取得或加速锁箱；「沉默送貨人」直接取得四星金卡手下且不给三合一奖励；「寶藏鸚鵡」把累计战斗伤害转成黄金之触，再把旅店手下升级为金卡；「餅乾船長」以死亡之声取得主厨精选，用指定类型补充不同的同类型手下。这些是两局实锤出现的其他 S14 新卡，Intro 必须讲清它们各自的机制角色，不能全部归类成刷经济。
5. `BG36_524`「海洋強奪者」虽与金卡计数主题相关，但两条来源均没有可靠画面，必须从实战机制表和 Intro 卡牌展示中排除。
6. 郭枫荷通过控制三联动画和操作节奏提高单位时间买卖次数；瓦莉拉使用霍格船长的英雄技能稳定提供循环所需金币。
7. 最终结果必须用画面可见的约数表达，例如“数值进入数千、终局逼近一万”，不得把扫描摘要中的标题数字当成未经验证的固定上限。

具体卡牌效果与正式繁中名仍需在下载后通过最新 HearthstoneJSON 数据和官方 zhTW 卡面逐张核对。当前需重点核验的官方 ID 为：

- `BG36_523` — `Enterprising Escapee`
- `BG36_520t` — `Lockbox`
- `BG36_344` — `Hooktusk, Master Marauder`
- `BG36_521` — `Locked-up Mutineer`
- `BG36_343` — `Silent Deliverer`
- `BG36_760` — `Cookie Captain`
- `BG36_763` — `Treasure Parrot`

Intro 固定以「你敢相信？」开头，使用客观机制描述，删除拟人和松散比喻。叙事顺序固定为“逃脱者与锁箱的资源机制 → 其他新卡分别如何补锁箱、造金卡或补同类型资源 → 实际打出金卡后的计数 → 鉤牙如何以发现转化为其余海盗属性 → 两位主播的启动差异 → 近万结果与强度结论”。夸张感来自明确结果与强结论。结尾固定为「這套絕對是賽季初期斷層 T0，後續很可能被調整，趁改動前趕緊爽起來！」，表达版本初期的紧迫感，但不把尚未官宣的删除或削弱写成确定事实。未在两局实际出现的更新卡不得加入 Intro 卡牌展示。

## 4. 双素材分工

- 郭枫荷段负责展示高操作上限：逃脱者与锁箱如何支撑持续买卖、为什么暂缓三联可减少发现动画，以及成型后如何把操作吞吐转成极限数值。
- 瓦莉拉段负责展示稳定启动：霍格船长如何提供金币、双金逃脱者如何加速锁箱，以及普通观众更容易复现的循环节奏。
- 正片顺序固定为郭枫荷在前、瓦莉拉在后；Intro 把两者包装成“极限效率”和“稳定经济”两种启动方式，而不是互相冲突的唯一答案。

## 5. Intro 背景与封面视觉

背景采用“深蓝海盗金库”方向，并延续上一期验证有效的高对比构图：

- 场景为无人物的暗色海盗船金库或地下宝库。
- 低处中央只设置一个熔金发光锁箱，作为唯一主焦点。
- 金币、金色链环和能量轨迹围绕锁箱形成清晰的闭合循环，用视觉直接表达“新经济循环”。
- 使用深海蓝、青绿环境光与熔金橙形成强冷暖对比；避免浑浊中间调。
- 右侧女老板区域、左下字幕区和顶部标题条保持暗、低细节。
- 不生成角色、海盗人物、动物、卡牌、文字、数字、Logo 或游戏 UI。

缩略图沿用频道标准两层标题、官方繁中核心卡牌、女老板和左上频道 Logo。优先使用「積極的逃脫者」或「帶鎖箱」中在 640px 预览下更能读出机制的一张卡；如单卡不足以表达闭环，可使用双卡扇形组合，但不得遮挡官方卡名。

## 6. 制作流程与检查点

1. 下载两条源并验证媒体完整性。
2. 提取 speech，分别执行一次 raw ASR，结合弹幕和关键帧写两局内容理解，并为实际出现的每张 BG36 新海盗记录时间点与机制角色。
3. 提交内容理解、实际新卡机制表与详细机制 Intro 文案，完成审核检查点 1。
4. 核对官方 zhTW 卡面和术语，在 TTS 前修正文案。
5. 生成高对比锁箱背景、TTS、对齐字幕和动态卡牌 Intro。
6. 提交 `intro.mp4` 与 640px 背景预览，完成审核检查点 2。
7. 检查源片硬字幕，清理需要烧录的繁中字幕；原始 ASR 不得重跑。
8. 生成版权安全音乐床，烧录两段正片，只在第一段后追加一次 CTA，再合并章节。
9. 生成固定标题缩略图与 YouTube 元数据，提交上传前最终审核。
10. 经明确授权后公开上传，加入 S14 独立播放列表并发布繁体订阅评论。

## 7. 错误处理与验收

- 任一源下载截断、无有效音轨、分辨率不足或缺少弹幕时，先修复或更换来源，不带病制作。
- ASR 每个来源只执行一次；字幕清理只能修改文字，区块编号和时间戳必须完全一致。
- Intro 必须完整说明“花费金币 → 锁箱／加速 → 其他新卡补锁箱、造金卡或补同类型资源 → 金卡实际打出 → 发现触发鉤牙强化其余海盗”的顺序，不能只报卡名、只讲刷经济或只展示终盘数字。
- 收尾必须使用已选的「后续可能调整 + 趁改动前赶紧爽」版本，不得写成已经官宣删除、削弱或确定调整。
- 检查点 1 必须附一张实际新卡机制表；每张卡都要有视频来源、时间点和实际作用，没有画面或 speech 证据的卡不得进入 Intro。
- “锁箱经济”不等于自动返还金币；英雄技能、买卖和锁箱产出必须按视频中的真实作用分别描述。
- 背景在 640px 宽度仍应清楚看到单一熔金锁箱和循环轨迹，且字幕和女老板安全区没有竞争亮点。
- 缩略图必须显示 `鎖箱海盜` 与 `新經濟循環`，尺寸为 1280×720 且小于 2 MB。
- 最终视频必须为 1920×1080、30fps、H.264、AAC 48kHz 双声道，并通过完整解码和章节检查。
- 上传后必须出现在 S14 播放列表且不在 S13 播放列表。
