# S14 仙女龙流视频制作设计

## 目标

制作一期围绕 S14 新版龙族成长体系的繁体中文《炉石战记：英雄战场》教学视频。成片用两局实战说明同一核心体系的两种成型路径，并把新版核心卡的规则、触发条件和成长结果讲清楚。

本期主卖点为“新赛季新发明，龙族重新具备高上限”。扫描报告里的“仙女龙”“诗心龙”“千攻”等名称和数值只是候选线索；正式文案必须以原片画面、原始语音、弹幕和最新官方繁中卡面交叉核验。

## 已确认素材

1. 炉石郭枫荷：<https://www.bilibili.com/video/BV1ZbM26EE9H>
   - 标题：`新发明！谁说龙不强，龙族的真正玩法！`
   - 预期用途：展示新版纯龙成长引擎及上限。
2. 高冷难神衣锦夜行：<https://www.bilibili.com/video/BV1oxut6hEuJ>
   - 标题：`【夜吹的战棋日记2296】前朝余孽，小仙女硬生生把红龙抬高一个档次！`
   - 预期用途：展示经济转型、搜齐组件和另一条成型路线。

两局的最终定位和先后顺序以下载后的逐段证据分析为准。若其中一局并非同一核心体系，不强行拼接；应收窄为真实共同机制，或停下来重新选择第二素材。

## 内容设计

### 叙事结构

1. 45–50 秒动态 Intro：直接展示新版龙族的最终强度，再解释核心卡如何触发、如何叠加，以及两局分别解决的启动和终局问题。
2. 第一局：优先使用机制最完整、成长结果最强的一局，负责建立主体系。
3. 约 5 秒订阅 CTA：附加在第一局尾部，不单独成为章节。
4. 第二局：展示互补的经济或转型路线，避免重复讲解。
5. YouTube 章节：Intro、第一局、第二局三段，全部不少于 10 秒。

### Intro 文风

- 开头固定为 `你敢相信？`
- 强调“新版本”“新卡机制”和实际成长结果。
- 客观、直观、夸张表达强，减少拟人和比喻。
- 先说明触发条件，再说明收益与完整联动；不能只说“刷经济”。
- 只使用原片实际出现并经官方资料确认的卡牌。
- 不把“获得金卡”“打出金卡”“发现”“战吼”“亡语”等不同事件混写。
- 结尾使用“赛季初期断层 T0、赶紧学”一类紧迫句，但只有在两局表现足以支持时才写成确定判断；否则改为“赛季初期最值得学的龙族新体系”。

### 术语与证据

- 完整读取两段原始 ASR、弹幕和关键帧，建立带时间戳的机制表。
- 扫描报告中的“仙女龙”“诗心龙”“巴林达”“哨子”“悬赏令”等均视为待核别称。
- 正式字幕、Intro、卡面和 metadata 统一使用 HearthstoneJSON 最新版官方 zhTW 名称与规则文本。
- 每个 Intro 机制断言都必须能指向原片实际画面或语音证据，并与官方静态规则一致。
- “千攻”只能在能可靠读出己方随从数值时使用，不能把对手数值、战斗伤害或主播口述极值写成己方终局。

## 视觉设计

### 封面文字

用户指定文案原样使用：

```text
新赛季新发明！
龙族翻身！
```

`龙族翻身！`为最大字号主标题，`新赛季新发明！`作为上方次标题。背景不生成任何文字，最终文字由脚本排版，保证缩略图可读性。

### 封面构图

- 仙女龙作为唯一主视觉，置于画面中右区域；只在官方卡面确认后选择对应卡图。
- 背景使用高饱和深蓝、紫色与金色魔法能量，加入明确的中心爆发光、增长轨迹和强明暗对比。
- 左侧保留连续深色文字区，右下为频道女老板吉祥物及核心卡牌区。
- 不堆叠多个龙头、宝箱、无关随从或伪造卡牌文本。
- 先以 640×360 预览检查；主标题、次标题和核心卡名必须一眼可读。

### Intro 背景

- 生成一张与封面同主题但更克制的 1920×1080 龙族魔法场景。
- 保留左侧字幕安全区、卡牌展示区和右侧吉祥物安全区。
- 使用动态卡牌轮播展示实际讲到的新卡，顺序严格跟随首次提及时间。
- 原始背景不包含文字、徽标、UI 或额外角色。

## 制作流程

1. 预检工具、凭据、磁盘和现有工作区，建立独立项目目录 `output/fairy_dragon_s14/`。
2. 顺序下载两段 Bilibili 视频及 XML/ASS 弹幕，完整解码校验。
3. 为每个 BVID 分离 stems；每段只运行一次原始 ASR，使用 `--skip-cleanup`，保留 canonical raw SRT/JSON。
4. 阅读原始语音、弹幕和关键帧，写 `content_understanding.md`，确认共同核心、实际卡牌、触发顺序、两局分工和终局数值。
5. 核对官方 zhTW 卡名与卡面，制作 `terms_zhTW.md`、`subtitle_context.txt` 和所需卡牌素材。
6. 写 45–50 秒 Intro，生成 TTS/SRT；检查文案字符、音频尾部、字幕尾部和急迫结尾。
7. 生成吸睛背景并制作动态 Intro，逐张检查卡牌首次出现、字幕安全区和结尾完整性。
8. 仅修改 cleaned 字幕文本，不改变原始块 ID 和时间戳；统一繁体并重建 ASS。
9. 分别烧制两局，附加中插 CTA，合并为 1080p30 H.264/AAC 成片并写入章节。
10. 使用 `scripts/thumbnail_polish.py` 制作封面；创建繁体 metadata，包含两个 Bilibili 来源、唯一时间轴、音乐署名和前三个频道标签。
11. 完整解码、逐边界抽帧、封面缩略预览、字幕与机制复核，产出可上传文件。
12. 只有获得本期明确公开上传授权后，才上传到指定频道并仅加入 S14 流派教学及适用的主播播放列表；随后发布繁体订阅评论并使用项目清理工具回收旧缓存。

## 验收标准

- 两个来源均成功下载，视频、音频、弹幕和原始 ASR 完整。
- Intro 为 45–50 秒，开头固定、机制完整、官方繁中术语准确，结尾不截断。
- Intro 中每张卡均在首次提及时正确出现，卡名和规则可读。
- 成片为 1920×1080、30fps、H.264/AAC，完整解码无错，三章节边界无黑帧或时间戳倒退。
- 清理后的字幕保持原始块数、块 ID 和时间戳不变，并统一繁体。
- 封面为 1280×720、低于 2MB；640×360 下仍能读清 `新赛季新发明！` 与 `龙族翻身！`。
- metadata 仅有一个严格递增的时间轴块，包含两个唯一来源链接、完整音乐署名和 `#英雄戰場教學`。
- 未经本期明确授权，不执行公开上传、评论或清理。

## 失败处理

- 下载流损坏时先改用单流或 H.265 备选源并重新做完整解码，不在损坏素材上继续制作。
- ASR 失败时保留原始产物和日志，不重复无条件调用；只有确定缓存无效时才进行一次有记录的重试。
- 官方名称、规则或原片证据冲突时，以最新官方卡面与实际画面为准，并收窄文案。
- 两局无法证明同一核心体系时，暂停合并并报告证据差异，不通过模糊措辞掩盖。
- Intro、字幕、章节或成片任一验收失败时，只重做受影响阶段并复用其余缓存。
