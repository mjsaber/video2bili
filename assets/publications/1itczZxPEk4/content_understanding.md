鏈條：法術指向華麗機器人 → 巴琳達 ×2、墜盒再 ×2 → 每次都合體一個衛星 → 通用無人機在回合結束按合體次數給全場 +4/+5 → 德拉克瑞把回合結束再算一次。
**自動擋** = 無人機複製器 + 通用無人機：啟動一下、掛機多合體一次，省操作省金幣。
**手動擋** = 每回合把金幣花在旅店法術上，靠巴琳達 + 墜盒 + 華麗機器人把合體次數堆上去。

## 兩局合成的角度
1. 結果先行：郭楓荷一個回合結束 6900→17000，第一名。
2. 機制講清楚：一張法術四次 → 合體四次 → 回合結束翻倍。觀眾要學的是次數怎麼堆。
3. 決策：自動擋（複製器掛機）vs 手動擋（金幣換法術）。瓦莉拉金幣不缺卻選自動，第九回合自己認錯 → 有錢就手動。
4. 不宣傳「無限」「最穩」：郭楓荷中期兩次沒錢卡住；瓦莉拉無名次。
