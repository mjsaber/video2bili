## 机制核心（intro 角度：鉤牙作用 + 差异）

**上赛季（S13）倒轉**：空軍上將羅傑斯——「在你花費9枚金幣後，獲得一個隨機賞金」。賞金 = 一次性旅店法術（強健/敵意/自私/友善/富裕賞金：+4血×4 / +4攻×4 / 最左+6/+6 / 隨機手下 / 2金）。花錢→隨機一次性回報，線性、看臉。（本频道 deadsea 死海流已做過此版本）

**本赛季（S14）倒轉**：
1. 積極的逃脫者：花費5金→帶鎖箱；已有則提早1回合開啟。帶鎖箱：5回合後開啟→隨機金卡手下。
2. 打出金卡 → 『大師掠奪者』鉤牙（6星 4/4）：每次**發現**一張卡後，其他海盜+1/+1，**依本局打出過的金卡手下強化**；金色基礎+2/+2；不強化自己，多隻鉤牙互相餵。
3. 瑪卓薩斯匕首：每回合開始「發現」一個陣容手下的未加成分身（帶黑暗贈禮）→ 每回合穩定觸發鉤牙。寶藏鸚鵡（35點傷害→黃金之觸）與 銀河透鏡（複製旅店法術）補金卡/經濟。
4. 結果：回報從「一次性法術」變「永久全隊屬性」，觸發從「花9金」變「發現」，成長從線性變指數（郭 9回合 50 → 10回合 1K → 12回合 8K → 13回合全員破萬）。
